# Ivan Ma — portfolio

Personal portfolio site built with Vite + React.

```
npm install
npm run dev
npm run deploy
```

`npm run deploy` publishes `dist/` to the `gh-pages` branch, served at https://ivanma9.github.io/ivanma/.

`npm run stats` refreshes `src/stats.json` from GitHub for the Stats page; it needs the `gh` CLI logged in.
